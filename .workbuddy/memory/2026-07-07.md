# 2026-07-07

## 新增 Pages 页面功能

为插件添加了 AstrBot WebUI Pages 支持，包含三个功能子页面：

### 目录结构
```
pages/
├── api-overview/index.html    # API 总览：表格展示所有已配置 API
├── api-config/index.html       # API 配置：可视化增删改查
└── api-stats/index.html        # 调用统计：60s 滑动窗口统计
```

### 后端改动 (main.py)
- 注册 6 个 Web API 路由（overview/data, config/list/add/update/delete, stats/data）
- 新增 `_save_config()` 持久化方法，使用 `astrbot.core.star.config.update_config`
- 新增 `_rebuild_maps()` 配置变更后重建指令映射
- 统计 API 从 `rate_limiter.api_calls` 读取实时数据

### 技术要点
- Pages 通过 `window.AstrBotPluginPage` bridge 与后端通信
- 使用 `context.register_web_api()` 注册路由
- 前端请求 endpoint 不带插件名，Dashboard 自动转发
- 配置修改后自动持久化并重建内存映射

按照 https://docs.astrbot.app/dev/star/guides/plugin-pages.html 规范检查并修复：
