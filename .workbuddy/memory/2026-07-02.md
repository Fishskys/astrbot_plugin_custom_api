## 代码审查与全部修复

对 astrbot_plugin_custom_api 进行了全面的代码审查和修复，涉及 8 个源文件。

### 修复的 P0 级 Bug
- **`main.py:38` & `main_test.py:38`**: 修复拼写错误 `"defalult"` → `"default"`（会导致 KeyError）
- **`core/response_handle.py:142`**: 修复变量名错误 `img` → `data`（会导致 NameError）
- **`main.py:27` & `main_test.py:27`**: 修复配置键名不匹配 `"global_timeout"` → `"global_default_timeout"`（用户配置的超时值无法生效）
- **`main_test.py:217`**: 修复 `process_select` 返回值未解包（会导致 TypeError）

### 修复的 P1 级问题
- **`core/response_handle.py`**: 音频/视频二进制处理中改用 `delete=False` + `try/finally` 模式，避免异步生成器中临时文件提前删除
- **`core/RateLimiter.py`**: 新增 `shutdown()` 方法，使用 `asyncio.Event` 替代 `while True` 实现可取消的清理任务
- **`core/client.py`**: 二进制响应增加 `Content-Length` 大小检查，防止大文件 OOM

### 代码质量改进
- 所有文件中 `from xxx import *` 替换为显式导入
- `core/utils.py`: `get_nested_value` 增加 try/except 异常处理，清理未使用的导入

- `core/response_handle.py`: 统一构造函数风格 `Comp.Record(url=data)` / `Comp.Video(url=data)`
